# Инициализация проекта

## Быстрый старт для пустого проекта

Если вы начинаете с пустой базы данных, используйте команду инициализации:

```bash
sail artisan project:init
```

Или без подтверждения:

```bash
sail artisan project:init --force
```

**💡 Совет:** Эта команда безопасна - она использует `firstOrCreate`, поэтому не создаст дубликаты данных при повторном запуске.

## Что будет создано

### 👤 Пользователи
- **Администратор**
  - Email: `admin@example.com`
  - Пароль: `password`
  - Роль: Admin

### 📄 Типы файлов
- PDF документ
- Excel таблица
- Изображение (jpg, png, gif)
- Word документ
- Чертёж или схема

### 💰 Типы расходов
- Зарплаты
- Личные доли
- Реклама
- Инструменты
- Рабочие расходы
- Услуги
- Материалы
- Транспорт

## Альтернативный способ

Вы также можете запустить seeder напрямую:

```bash
sail artisan db:seed --class=InitialDataSeeder
```

## Полная инициализация с тестовыми данными

Если вам нужны тестовые данные (проекты, продукты, закупки и т.д.):

```bash
sail artisan db:seed
```

## Восстановление базы данных

Если нужно полностью очистить и пересоздать базу:

```bash
# Удалить все таблицы и создать заново
sail artisan migrate:fresh

# Добавить только ключевые данные
sail artisan project:init --force

# ИЛИ добавить все тестовые данные
sail artisan migrate:fresh --seed
```

## Безопасность

⚠️ **ВАЖНО:** После первого входа обязательно измените пароль администратора!

## Разработка

При разработке вы можете использовать эти команды для быстрого сброса и инициализации:

```bash
# Полный сброс для тестирования
sail artisan migrate:fresh && sail artisan project:init --force
```
